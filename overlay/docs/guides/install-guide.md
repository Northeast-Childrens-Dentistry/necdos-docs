---
title: Installation
---

NECD OS is installed and managed by the administrator. Staff never need to install or reinstall the system.

Administrators: NECD OS is a signed image published at `ghcr.io/northeast-childrens-dentistry/necdos`. Clients only accept images signed with the NECD key, and the `stable` tag always points to the last image that passed every check. See [Updates](/necd/updates) and [Rollback](/necd/rollback).
