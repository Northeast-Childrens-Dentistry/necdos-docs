NECD OS is the workstation system used at Northeast Children's Dentistry. It is built on [Aurora](https://github.com/ublue-os/aurora), a KDE Plasma desktop from the Universal Blue project, with the clinic's apps and branding added.

## Using these docs

- **Staff:** start with [Clinic apps](/necd/clinic-apps) and [Updates](/necd/updates). If something is wrong, call the administrator.
- **Administrators:** see [Rollback](/necd/rollback). The other guides cover the Aurora system underneath.

Most of the guides are adapted from the Aurora documentation and are kept up to date from it automatically.
